# @netofings/cli

Modern TypeScript CLI for Netofings.

## Commands

- `netofings monitor --host mqtt://localhost --interval 5000`

## Controls (monitor)

- `q` or `esc`: exit
- `left` and `right`: move across agents
- `up` and `down`: move across metrics

## Development

```bash
npm run build
npm run test
npm run dev -- monitor
```
